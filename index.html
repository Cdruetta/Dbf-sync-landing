Sus archivos .dbf y .dbt, copiados solos en segundo plano.

DBF Sync es un servicio de Windows que copia los archivos .dbf (y sus .dbt de memos) de una carpeta a otra cada cierto tiempo. No necesita ventanas abiertas, funciona también en Windows de 32 bits y arranca junto con el equipo.

Servicio de WindowsDBFGuardian

Carpeta destinoC:\sis\web

Se inicia con Windows y se recupera ante fallos. No borra ni mueve los originales: el destino siempre queda con la versión actual de cada archivo (reemplaza, sin copias (1), (2)…).

1. Elija la carpeta según su Windows

Copie la carpeta completa del paquete, nunca archivos sueltos: el configurador, el servicio y config.json deben quedar juntos.

Carpeta a copiar
deploy\x86\
Archivo a abrir
dbf_sync_manager_x86.exe
Servicio incluido
dbf_sync_service_x86.exe
Use una ruta fija y definitiva, por ejemplo C:\DBFSync\. No instale desde Descargas ni desde una carpeta temporal: Windows registra esa ruta y, si la mueve o la borra, el servicio deja de funcionar.

2. Primera instalación

Son cinco pasos y el último es opcional.

  1. Copie la carpeta

    Pegue deploy\x86\ o deploy\x64\ en la PC, por ejemplo en C:\DBFSync\.

  2. Abra el configurador como administrador

    • 32-bit: dbf_sync_manager_x86.exe
    • 64-bit: dbf_sync_manager_x64.exe

  3. Revise los datos y pulse Guardar config

    Los valores recomendados están en la sección siguiente.

  4. Pulse Instalar / Iniciar

    • Windows pedirá permiso de administrador (UAC): acepte para continuar.
    • Se instala e inicia el servicio DBFGuardian con inicio automático.

  5. Cree accesos directos (opcional)

    Desde el configurador puede crearlos en el Escritorio: abrir el configurador, iniciar el servicio, detenerlo, o correr una sincronización en consola para pruebas. Quitar accesos los elimina.

Al terminar, el servicio queda activo y se inicia solo con Windows.

Estado a la vista

Abajo del configurador se ve el servicio en color: verde activo, rojo detenido y ámbar no instalado. Se actualiza solo cada 8 segundos.

Atajos

Ctrl+S guarda, F5 actualiza el estado y Esc cierra (pregunta si hay cambios sin guardar).

Ventana cómoda

Recuerda tamaño y posición, y en pantallas con escalado 125% o 150% el texto se ve nítido.

4. Cómo se copian los archivos

Siempre se copia; nunca se mueve ni se borra el original.

Reemplaza siempre

Cada ciclo copia cada archivo con su nombre original y reemplaza la versión anterior del destino con la actual del origen, aunque el contenido no haya cambiado.

Sin copias (1), (2)

Nunca se crean CLIENTES (1).DBF, CLIENTES (2).DBF… El destino siempre tiene un solo archivo por nombre.

Destino protegido

Si alguien modifica o borra un archivo del destino, el ciclo siguiente lo restaura con la versión del origen.

Archivos .dbt de memos: cuando un .dbf tiene campos memo, sus textos largos viven en un archivo aparte con el mismo nombre (CLIENTES.DBF → CLIENTES.DBT). El servicio lo copia automáticamente junto a su .dbf, con las mismas reglas (reemplazando la versión anterior). No hay que seleccionarlo ni configurar nada.
PasoQué hace el servicio
1Lee config.json y recorre cada ubicación (origen → destino).
2Toma los .dbf elegidos (o todos los de la extensión), junto con sus .dbt de memos si existen, y verifica que hayan terminado de escribirse.
3Copia cada archivo a su nombre original en destino, reemplazando la versión anterior de forma segura (igual para los .dbt).
4Copia, registra el resultado y avisa si la notificación está activada.

5. Compruebe que funciona

Tres chequeos rápidos, en este orden.

Estado del servicio

En el configurador debe verse ● Servicio: activo en verde. Por CMD, sc query DBFGuardian debe indicar ESTADO: 4 EN EJECUCIÓN (o RUNNING).

Carpeta destino

Verifique que en C:\sis\web (o la destino configurada) estén los .dbf copiados, y los .dbt de memos si los había.

Registro

Revise C:\sis\logs\dbf_sync.log. Con nivel PRODUCCION o WARNING es normal que haya pocas líneas o ninguna. Para una prueba visible, use DEBUG e intervalo 1 minuto, y después vuelva a los valores recomendados.

7. Si algo no funciona

Los problemas más habituales y su solución.

“No se encontró el ejecutable del servicio”

El configurador y el dbf_sync_service_*.exe no están en la misma carpeta. Copie de nuevo el paquete completo.

Pide permiso de administrador

Es normal: Windows lo exige para instalar, iniciar o detener el servicio.

El servicio no inicia

Revise C:\sis\logs\dbf_sync.log, verifique que las rutas existan y que la carpeta del programa no se haya movido. Luego use Instalar / Iniciar.

No hay líneas nuevas en el log

Con PRODUCCION o WARNING es normal si no hay novedades. Confirme el estado con sc query DBFGuardian.

La carpeta destino tiene archivos “(1)”, “(2)”…

Son restos de una versión anterior del programa o de copias hechas a mano. La versión actual nunca crea archivos «(1)», «(2)»: siempre reemplaza con el nombre original. Puede borrar a mano esas copias viejas.

Moví la carpeta del programa

El servicio apunta a la ruta anterior. Ejecute Instalar / Iniciar desde la nueva ubicación fija.
