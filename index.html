Sus archivos .dbf, copiados solos en segundo plano.

DBF Sync es un servicio de Windows que copia los archivos .dbf de una carpeta a otra cada cierto tiempo. No necesita ventanas abiertas, funciona también en Windows de 32 bits y arranca junto con el equipo.

→
Servicio de WindowsDBFGuardian

Carpeta destinoC:\sis\web

Se inicia con Windows y se recupera ante fallos. No borra ni mueve los archivos originales.

1. Elija la carpeta según su Windows

Copie la carpeta completa del paquete, nunca archivos sueltos: el configurador, el servicio y config.json deben quedar juntos.

Carpeta a copiar
deploy\x86\
Archivo a abrir
dbf_sync_manager_x86.exe
Servicio incluido
dbf_sync_service_x86.exe
Use una ruta fija y definitiva, por ejemplo C:\DBFSync\. No instale desde Descargas ni desde una carpeta temporal: Windows registra esa ruta y, si la mueve o la borra, el servicio deja de funcionar.

2. Primera instalación

Son cinco pasos y el último es opcional.

  1. Copie la carpeta

    Pegue deploy\x86\ o deploy\x64\ en la PC, por ejemplo en C:\DBFSync\.

  2. Abra el configurador como administrador

    • 32-bit: dbf_sync_manager_x86.exe
    • 64-bit: dbf_sync_manager_x64.exe

  3. Revise los datos y pulse Guardar config

    Los valores recomendados están en la sección siguiente.

  4. Pulse Instalar / Iniciar

    • Windows pedirá permiso de administrador (UAC): acepte para continuar.
    • Se instala e inicia el servicio DBFGuardian con inicio automático.

  5. Cree accesos directos (opcional)

    Desde el configurador puede crearlos en el Escritorio: abrir el configurador, iniciar el servicio, detenerlo, o correr una sincronización en consola para pruebas. Quitar accesos los elimina.

Al terminar, el servicio queda activo y se inicia solo con Windows.

Recomendado. Solo avisos y errores, con mínimo uso de disco y CPU.

Si cambia la configuración con el servicio en marcha, reinícielo con Detener e Iniciar para aplicar los cambios.

4. Compruebe que funciona

Tres chequeos rápidos, en este orden.

Estado del servicio

Abra CMD y ejecute el comando. Debe indicar RUNNING.

sc query DBFGuardian

Carpeta destino

Verifique que en C:\sis\web (o la destino configurada) estén los .dbf copiados.

Registro

Revise C:\sis\logs\dbf_sync.log. Con nivel PRODUCCION o WARNING es normal que haya pocas líneas o ninguna. Para una prueba visible, use DEBUG e intervalo 1 minuto, y después vuelva a los valores recomendados.

5. Acciones comunes

Necesito…Qué hacer
Cambiar rutas o intervaloConfigurador → editar → Guardar config → reiniciar el servicio.
Iniciar o detenerConfigurador (UAC) o, como administrador: net start DBFGuardian / net stop DBFGuardian
DesinstalarConfigurador → Desinstalar (UAC), o uninstall_service.bat como administrador.
Actualizar el programaDetenga o desinstale, reemplace los archivos en la misma carpeta fija por los del paquete nuevo y vuelva a Instalar / Iniciar.

6. Si algo no funciona

Los problemas más habituales y su solución.

“No se encontró el ejecutable del servicio”

El configurador y el dbf_sync_service_*.exe no están en la misma carpeta. Copie de nuevo el paquete completo.

Pide permiso de administrador

Es normal: Windows lo exige para instalar, iniciar o detener el servicio.

El servicio no inicia

Revise C:\sis\logs\dbf_sync.log, verifique que las rutas existan y que la carpeta del programa no se haya movido. Luego use Instalar / Iniciar.

No hay líneas nuevas en el log

Con PRODUCCION o WARNING es normal si no hay novedades. Confirme el estado con sc query DBFGuardian.

Moví la carpeta del programa

El servicio apunta a la ruta anterior. Ejecute Instalar / Iniciar desde la nueva ubicación fija.
